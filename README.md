NAME:
AV工具 - A new cli application

USAGE:
AV工具 [global options] command [command options] [arguments...]

DESCRIPTION:
查询/nfo

COMMANDS:
info     info -no=avb-123

help, h  Shows a list of commands or help for one command

GLOBAL OPTIONS:
--help, -h  show help
